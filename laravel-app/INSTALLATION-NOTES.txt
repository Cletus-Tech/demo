Laravel Integration Notes

This folder is a reusable Laravel 12 integration package, not a complete generated Laravel framework distribution. Start with a fresh Laravel 12 app, then merge these files. Do not overwrite an existing host application's routes, authentication, migrations, bootstrap or composer files.

The dashboard Blade view loads public/js/broker-api.js. That adapter uses same-origin Laravel endpoints protected by Sanctum session authentication and CSRF cookies. It does not use the Supabase browser client.

Referral codes are generated for accounts and optional referral codes on registration record sign-up attribution. No referral rewards or payouts are enabled.

Demo deposits and withdrawals affect simulated USD only. Buy, sell, convert and leveraged position quantities are calculated on the server from the current seeded demo prices; the browser does not submit an execution price. No live market feed, payments, custody or exchange execution is connected.

See README.md for setup, route contracts, demo limitations and the required host-application smoke tests.

An idempotent Database/Seeders/BrokerDemoSeeder.php restores the baseline demo assets. To optionally create an ordinary demo login, set BROKER_DEMO_USER_EMAIL and BROKER_DEMO_USER_PASSWORD (at least 12 characters) in the host environment before running `php artisan db:seed --class='Database\\Seeders\\BrokerDemoSeeder'`. The seeder never grants an admin role or overwrites an existing password/status.

Feature tests are in tests/Feature/BrokerApiTest.php. Copy them into the host application's tests/Feature directory and run php artisan test. The GitHub Actions integration matrix provisions a fresh Laravel 12 host and runs the Blade compile, route listing and feature tests.

USD is the fixed demo accounting currency (price 1). Other active assets may receive small simulated server-side price ticks. Leveraged positions are restricted to non-fiat assets. The chart's earlier candles are generated illustration, not historical exchange data.
