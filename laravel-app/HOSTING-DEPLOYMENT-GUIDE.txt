DEMO BROKER — HOSTING HANDOVER
Laravel 12 application | PHP 8.2+

PACKAGE CONTENTS
This is the Laravel source application. It is not a static HTML website. It must be hosted on a server that executes PHP.

SERVER REQUIREMENTS
- PHP 8.2 or newer
- Composer 2
- MySQL 8 or compatible MariaDB
- PHP extensions: PDO, pdo_mysql, mbstring, OpenSSL, tokenizer, XML, Ctype, JSON, Fileinfo, and cURL
- HTTPS enabled
- Ability to set the website document root to the application's public/ folder

INSTALLATION
1. Extract the ZIP on the hosting account.
2. Keep the complete application folder outside the public web root where possible.
3. Configure the domain's document root to the Laravel application's public/ folder. Do not point the domain at the application root.
4. From the application root, run:
   composer install --no-dev --optimize-autoloader
5. Copy .env.example to .env and configure:
   APP_ENV=production
   APP_DEBUG=false
   APP_URL=https://YOUR-DOMAIN
   APP_KEY= (generate a unique key with: php artisan key:generate)
   DB_CONNECTION=mysql
   DB_HOST= (hosting database host)
   DB_PORT=3306
   DB_DATABASE= (database name)
   DB_USERNAME= (database user)
   DB_PASSWORD= (database password)
   MAIL_MAILER= (host's SMTP mailer)
   MAIL_HOST, MAIL_PORT, MAIL_USERNAME, MAIL_PASSWORD, MAIL_FROM_ADDRESS
   SESSION_SECURE_COOKIE=true
6. Ensure storage/ and bootstrap/cache/ are writable by the PHP process.
7. Run from the application root:
   php artisan migrate --force
   php artisan config:cache
   php artisan route:cache
   php artisan view:cache
8. Register the owner account and verify its email. Promote only the owner's account:
   php artisan tinker
   App\Models\User::where('email', 'OWNER_EMAIL')->update(['role' => 'superadmin', 'account_status' => 'active']);
9. Test login, registration/email verification, password reset, dashboard, demo deposit/withdraw, spot buy/sell, conversion, leveraged positions, TP/SL and admin access.

IMPORTANT
- Never upload a real .env file or reuse a development APP_KEY. Set production secrets on the host.
- Existing Supabase users, passwords, balances, history and referrals are NOT automatically migrated.
- This is a DEMO SIMULATION. Prices and balances are simulated; there are no real deposits, withdrawals, exchange connections, custody or live trades.
- Keep the original static demo online until the owner and client accept the Laravel deployment.
- The project was tested in CI using PHP 8.3, SQLite feature tests and MySQL 8 migrations. A final browser acceptance test on the target host is still required.
